# Checked-in mypy tests/ advisory baseline for scripts/lint.sh.

# The file holds exactly one value: the number on the last line. Everything
# else is a comment. scripts/lint.sh fails if it finds more than one value, so
# lowering the baseline means editing that last line, not adding another.
#
# Take the number from a CI lint job ("Found N errors in" under "ratchet —
# tests/ only"), never from a macOS run. CI runs on Linux, which installs the
# `sys_platform == "linux"` dependencies (cysystemd, inky, gpiod, spidev) that
# a macOS checkout skips. Those change what mypy can resolve through
# follow_imports, so a macOS count runs a little lower and would fail the next
# Linux CI run if committed. A lower local count passes as "ratchet improved".
