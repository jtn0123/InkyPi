# Checked-in mypy tests/ baseline for scripts/lint.sh, which compares it with
# a strict mypy run through scripts/mypy_ratchet.py.

# Below these comments is one line per `path:error-code` fingerprint, with the
# number of errors mypy reports for it. lint.sh fails when a fingerprint is
# new, has more or fewer errors than listed, or has gone, and prints only
# those differences. After fixing errors, rewrite the list (this header is
# kept; --update replaces everything below it):
#
#   python scripts/mypy_ratchet.py tests scripts/mypy_tests_baseline.txt --update
#
# CI runs on Linux, which installs the `sys_platform == "linux"` dependencies
# (cysystemd, inky, gpiod, spidev) that a macOS checkout skips. Those change
# what mypy can resolve through follow_imports. When a macOS run and the CI
# lint job disagree, commit the list the CI job wants.
