# Checked-in mypy scripts/ baseline for scripts/lint.sh, which compares it with
# a strict mypy run through scripts/mypy_ratchet.py.
#
# Below these comments is one line per `path:error-code` fingerprint, with the
# number of errors mypy reports for it. lint.sh fails when a fingerprint is
# new, has more or fewer errors than listed, or has gone, and prints only
# those differences. After fixing errors, rewrite the list (this header is
# kept; --update replaces everything below it):
#
#   python scripts/mypy_ratchet.py scripts scripts/mypy_scripts_baseline.txt --update
#
# The list is empty: scripts/ is clean, and any error fails lint.
#
# CI runs on Linux, which installs the `sys_platform == "linux"` dependencies
# (memray among them) that a macOS checkout skips, so the two runs can differ.
# When they disagree, the CI lint job is the one to satisfy.
#
# History
#
# 92 -> 2 (2026-11-15): scripts/ was never type-checked before this pass. Its
# 92 errors were annotations (dict and list type arguments, untyped defs and
# callers), Optional and Any-returning json.loads results narrowed or annotated,
# Pillow's Optional PixelAccess replaced by a typed getpixel helper, and
# monkeypatches moved from bare assignment to unittest.mock.patch.object.
#
# 2 -> 0 (2026-11-15): the last two were defusedxml imports in coverage_gate.py.
# types-defusedxml is now in the dev group; with real types, mypy also caught
# that getroot() can return None, which coverage_gate.py now checks.
